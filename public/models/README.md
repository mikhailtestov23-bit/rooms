# Character model slots

Primary character slot:

```text
public/models/character.vrm
```

Fallback character slot:

```text
public/models/character.glb
```

The game loads `character.vrm` first. If it is missing, it tries `character.glb`. If both files are missing, it keeps the current procedural character.

The current `character.glb` is generated by:

```text
npm run model:character
```

You can also use the top-right character button in the running game to select a local `.vrm` or `.glb` file. The selected model is stored in the browser and restored on the next launch. The rotate button flips the model by 180 degrees, and the reset button returns to the procedural character.

Useful local test URLs:

```text
http://127.0.0.1:5173/?character=procedural
http://127.0.0.1:5173/?model=/models/character.vrm
http://127.0.0.1:5173/?model=/models/character.vrm&modelRotation=180
http://127.0.0.1:5173/?model=/models/character.vrm&modelHeight=2.1
http://127.0.0.1:5173/?model=/models/character.glb
```

Recommended format: VRM 1.0 humanoid avatar with baked materials, spring bones for hair, and optional `Idle` / `Walk` animation clips.
